Framework workflow

Short commands.
Serious safeguards.

The same console handles discovery, diagnostics, source-derived documentation, audits, smoke testing and safe updates from the official rolling main branch.

  1. 01

    Build

    Use compact framework APIs and reusable UI directly in any domain root, subdomain or nested folder.

    php mystack make:controller Account
  2. 02

    Inspect

    Review routes, environment compatibility, migration state, queues and schedules without executing application work.

    php mystack doctor
  3. 03

    Verify

    Run the canonical regression suite, security audit and source-to-documentation consistency checks.

    php mystack smoke
  4. 04

    Stay current

    Compare exact bytes with the official main branch, stage changes, validate and roll back automatically on failure.

    php mystack update --check

Quick answers

Frequently asked questions.

?

What is MyStack?

A complete, zero-Composer PHP application framework: routing, security, database, UI, browser runtime, auth, payments, realtime, AI and observability in one folder.

?

Do I need Composer or NPM?

No. Zero runtime dependencies — no build step, no lockfiles, no transitive surprises. Ever.

?

Will it run on shared hosting?

Yes — that is the primary design target: cPanel/LiteSpeed, subfolder installs, portable paths and an .htaccess guard.

?

Is it free for commercial use?

Yes — Apache License 2.0 for the framework, MIT for the VS Code extension. Preserve the license and NOTICE, identify modifications.

?

Who maintains it?

Sakibur Rahman (sakibweb) — 5+ years of continuous development and testing, with full manuals in Bangla and English.

?

Can AI tools use it safely?

Yes — every public signature is machine-indexed from source, all AI crawlers are explicitly allowed, and the agent contract forbids invented APIs.
