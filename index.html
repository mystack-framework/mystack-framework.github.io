Framework workflow

Short commands.
Serious safeguards.

The same console handles discovery, diagnostics, source-derived documentation, audits, smoke testing and safe updates from the official rolling main branch.

  1. 01

    Build

    Use compact framework APIs and reusable UI directly in any domain root, subdomain or nested folder.

    php mystack make:controller Account
  2. 02

    Inspect

    Review routes, environment compatibility, migration state, queues and schedules without executing application work.

    php mystack doctor
  3. 03

    Verify

    Run the canonical regression suite, security audit and source-to-documentation consistency checks.

    php mystack smoke
  4. 04

    Stay current

    Compare exact bytes with the official main branch, stage changes, validate and roll back automatically on failure.

    php mystack update --check
